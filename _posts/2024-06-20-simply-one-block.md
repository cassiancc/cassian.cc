Simply One Block is an optimization modpack for 22w13oneblockatatime, the April Fools snapshot for the never-released One Block at a Time Update.<!--more--> (yes, I did it again)




Just like my last optimization pack for 20w14infinite, as far as I know this is also the first and only public modpack for 22w13oneblockatatime. The Modrinth page contains a full description of the gameplay changes this version has made, as unlike 20w14infinite, they are significant.

<hr>

This modpack is available [on Modrinth](https://modrinth.com/modpack/simply-one-block) for Minecraft: Java Edition 22w13oneblockatatime.
