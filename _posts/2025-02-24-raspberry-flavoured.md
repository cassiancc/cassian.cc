The first pre-release for the next version of the Raspberry Flavoured modpack is out, featuring a custom mod I developed that fixes a lot of its issues! 
<!--more-->

Raspberry Flavoured describes itself as a modpack focused on exploring, farming & taking things easy... but not too easy!

There's been a lot of work put into this pack, so if you're looking for a new pack, give it a try! 

The core mod is also available separately for anyone running a modpack with similar mods.

This mod and modpack are available for Minecraft: Java Edition 1.19.2.
